# Сбор находок на GitHub — бесплатно, без карты и без компьютера

GitHub запускает сборщик по расписанию на своих серверах. Ваш Mac при этом
может быть выключен. Карта не нужна: регистрация бесплатная, а на публичных
репозиториях минуты Actions не ограничены.

## Что нужно

- Аккаунт GitHub (бесплатный, без карты)
- Публичный репозиторий с кодом
- Два секрета: адрес сервера и токен

## Шаги

### 1. Создайте репозиторий

На github.com → **New repository** → имя `polka` → выберите **Public** →
Create. Карта не потребуется.

### 2. Залейте код

В терминале на Mac, из папки проекта:

```bash
cd "/Users/nikitagereev/PyCharmMiscProject/amvera-upload"
git remote add github https://github.com/ВАШ_ЛОГИН/polka.git
git push github master
```

Если попросит пароль — нужен **токен доступа**, а не пароль от аккаунта:
GitHub → Settings → Developer settings → Personal access tokens →
Tokens (classic) → Generate new token (classic) → галочка `repo` → скопировать.
Вставляйте его вместо пароля.

### 3. Добавьте секреты

В репозитории: **Settings → Secrets and variables → Actions →
New repository secret**. Добавьте два:

| Имя | Значение |
|---|---|
| `POLKA_SERVER` | `https://polka-mini-app-nikicev2009.mia0.amvera.tech` |
| `POLKA_INGEST_TOKEN` | токен, который вы задали в Amvera |

Токен хранится в секретах и в код не попадает — репозиторий может быть публичным.

### 4. Проверьте

Вкладка **Actions** → слева «Сбор находок» → кнопка **Run workflow**.

Через минуту в логе появится:

```
найдено карточек: 50
отправлено: принято 48, дублей 2, пропущено 0
```

Значит всё работает. Дальше сбор идёт сам **каждые 30 минут**.

### 5. Выключите сборщик на Mac

```bash
launchctl unload ~/Library/LaunchAgents/com.polka.collector.plist
```

Теперь Mac можно закрывать и выключать — сбор идёт на GitHub.

## Если Авито заблокирует GitHub

Runner'ы GitHub — это дата-центр, и Авито может ответить `429`.
Библиотека `curl_cffi` подделывает отпечаток Safari, и обычно этого хватает,
но гарантии нет. Признак — в логе Actions:

```
⛔ HTTP 429 — доступ ограничен по IP
```

Тогда вернитесь к сбору на Mac (шаг 5 наоборот) или возьмите бесплатный
сервер Oracle Always Free — но для него нужна карта для проверки.

## Ограничения варианта

- GitHub может задержать запуск по расписанию на 5–15 минут при нагрузке
- Если 60 дней не будет активности в репозитории, GitHub выключит расписание —
  заходите раз в месяц и жмите Run workflow
