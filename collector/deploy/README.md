# Круглосуточный сбор: отдельный сервер

Нужен, чтобы **не держать включённым Mac**. Amvera для сбора не годится:
там сборщик укладывает контейнер (проверено дважды).

## Что купить

Небольшой VPS с Ubuntu — от **200 ₽/мес** (Timeweb, Reg.ru, aeza, VDSina).
Хватит 1 ядра и 1 ГБ памяти: сборщик почти не потребляет.

Регион — Россия: Авито терпимее к российским адресам, а библиотека
`curl_cffi` подделывает отпечаток Safari, поэтому блокировки по IP обходятся.

## Установка

1. Скопируйте на сервер папку `collector` целиком, вместе с `config.json`
   (в нём токен — он нужен для отправки находок):

   ```bash
   scp -r collector root@ВАШ_IP:/root/
   ```

2. Зайдите на сервер и запустите установщик:

   ```bash
   ssh root@ВАШ_IP
   cd /root/collector
   bash deploy/install.sh
   ```

3. Проверьте:

   ```bash
   systemctl status polka-collector     # работает ли
   journalctl -u polka-collector -f     # что делает прямо сейчас
   ```

Через минуту в логе появится `найдено карточек: 50` и `принято N` —
значит находки идут на ваш сервер Amvera и в бота.

## Управление

```bash
systemctl stop polka-collector      # остановить
systemctl start polka-collector     # запустить
systemctl disable polka-collector   # убрать из автозапуска
```

## Можно ли обойтись без VPS

**Да, если Amvera поднять до тарифа с 2 ГБ памяти** — тогда сборщик
заработает прямо там (код готов, включается переменной `COLLECTOR_ENABLED=1`).
Но нужно проверить, что контейнер выдержит: на текущем тарифе он падает.
