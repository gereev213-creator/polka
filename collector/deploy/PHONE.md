## Важное про один Wi-Fi (прочитайте первым)

Все ваши устройства выходят в интернет через **один внешний IP**. Это и хорошо
(Авито пускает домашние адреса), и требует двух правил:

1. **Описания собирает только телефон.** Не запускайте сборщик на Mac в то же
   время: два клиента с одного IP удваивают частоту запросов, и Авито начинает
   отбивать обоих (429/439). Для проверки — запустили, посмотрели, остановили.
2. **Выдача остаётся в облаке.** GitHub Actions собирает список объявлений с
   любого IP и уже это делает каждые 20 минут. Телефону оставляем только то,
   что без домашнего IP недоступно: **описания и тип продавца** (АКБ,
   состояние, «не вскрывался», частник/магазин).

Так два сборщика не мешают друг другу и не тратят зря запросы.

## Режим «только описания» — что запускать на телефоне

```bash
cd ~/polka-collector
POLKA_SERVER=https://polka-mini-app-nikicev2009.mia0.amvera.tech \
POLKA_INGEST_TOKEN=ваш_токен \
python3 collect.py --details-only 15 --loop --every 600
```

Что это значит: каждые ~10 минут телефон спрашивает у сервера, каким карточкам
нужно описание, открывает их по одной с паузой 5–11 секунд и присылает текст
обратно. Пятнадцать карточек за проход — это щадящая нагрузка на домашний IP,
которым вы пользуетесь и сами.

Один проход без цикла (проверить, что работает):

```bash
POLKA_SERVER=https://polka-mini-app-nikicev2009.mia0.amvera.tech \
POLKA_INGEST_TOKEN=ваш_токен python3 collect.py --details-only 3
```

Если ответ «Авито не пускает на страницы объявлений с этого IP» — проверьте
`python3 collect.py --check-proxy`: возможно, Wi-Fi раздаёт адрес, который
Авито не любит, или телефон ходит через VPN.

### Чтобы телефон не засыпал

- В Termux один раз выполните `termux-wake-lock` (или добавьте в автозапуск).
- В настройках Android для Termux выключите экономию батареи
  («Батарея» → «Без ограничений»), иначе система усыпит сборщик.
- Wi-Fi не должен отключаться при блокировке экрана: «Настройки → Wi-Fi →
  Дополнительно → Не отключать Wi-Fi в спящем режиме».
- Держите телефон на зарядке.

# Сбор на старом Android-телефоне

Лучший бесплатный вариант: **Авито не блокирует мобильные и домашние IP**,
а телефон уже есть. Карта и VPS не нужны.

## Что понадобится

- Старый Android-телефон
- Зарядка (телефон будет всё время включён)
- Wi-Fi или мобильный интернет

## Шаг 1. Поставить Termux

**Скачивайте из F-Droid, а не из Play Маркета:** там версия устарела и
не работает. Ссылка: f-droid.org → поиск «Termux».

Также поставьте оттуда **Termux:Boot** — он нужен для автозапуска
после перезагрузки телефона.

## Шаг 2. Закинуть на телефон два файла

С телефона отправьте себе в Telegram (в «Избранное»):

- `collect.py` — из папки `collector` на Mac
- `config.json` — оттуда же (в нём токен)

Откройте в Telegram оба файла и скачайте — они попадут в «Загрузки».

## Шаг 3. Запустить установщик

Откройте Termux и вставьте:

```bash
cd ~/storage/downloads
bash phone-setup.sh
```

Если файла `phone-setup.sh` нет — отправьте его себе так же, как в шаге 2.

Установщик сам: поставит Python, библиотеку, найдёт файлы в «Загрузках»,
разрешит работу без сна и настроит автозапуск.

## Шаг 4. Проверить

```bash
tail -f ~/polka.log
```

Должно появиться:

```
→ avito: https://www.avito.ru/all/telefony?s=104
  найдено карточек: 50
  отправлено: принято 48, дублей 2, пропущено 0
```

`принято 48` — находки идут на ваш сервер и в бота.

## Шаг 5. Настройки телефона

Чтобы Android не убил сборщик:

1. **Настройки → Батарея → Termux → Без ограничений** (отключить оптимизацию)
2. Не закрывайте Termux из списка недавних приложений
3. Держите телефон на зарядке

## Управление

```bash
tail -f ~/polka.log        # что происходит
pkill -f collect.py        # остановить
cd ~/polka && nohup python collect.py --loop --every 900 >> ~/polka.log 2>&1 &   # запустить
```

## Если что-то не так

**`⛔ HTTP 429`** — Авито ограничил частоту. Увеличьте интервал:
`--every 1800` вместо `--every 900`.

**`найдено карточек: 0`** — изменилась вёрстка Авито. Пришлите лог.

**`Не заданы server и token`** — в `config.json` не вписан токен.

**Сбор пропадает после перезагрузки** — проверьте, что Termux:Boot
установлен и файл `~/.termux/boot/polka.sh` на месте.
