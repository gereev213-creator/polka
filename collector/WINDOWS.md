# Сборщик на старом ноутбуке с Windows

Зачем отдельная машина: Авито пускает только настоящий браузер с видимым
окном и только с домашнего IP. Значит нужен компьютер, который включён
постоянно. Старый ноутбук подходит идеально.

## 1. Поставить Python

Скачать Python 3.12 с python.org, при установке отметить
**"Add python.exe to PATH"**.

## 2. Скопировать папку

Скопировать на ноутбук всю папку `collector` с рабочего компьютера —
вместе с `config.json` (в нём адрес сервера и токен). Если config.json
нет, его нужно создать: скопировать файл с Мака, он в той же папке.

## 3. Установить зависимости

Двойной клик по `setup-windows.bat`. Он поставит `curl_cffi`, `playwright`
и скачает Chromium (~150 МБ). Нужен интернет.

## 4. Запустить

Двойной клик по `start-windows.bat`. Откроется окно Chromium — свернуть
его нельзя закрывать, но можно свернуть.

При первом запуске Авито может показать проверку: нажать «Продолжить»,
капчу решить. Один раз — дальше профиль запомнит cookies и не спросит.

Лог: `logs\collector.log`. Там видно `найдено карточек: N (с ценой M)`
и `отправлено: принято N`.

## 5. Чтобы ноутбук не засыпал

Выполнить в командной строке **от администратора**:

```
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /setacvalueindex SCHEME_CURRENT 4f971e89-eebd-4455-a8de-9e59040e7347 5ca83367-6e45-459f-a27b-476b1d01c936 0
powercfg /setactive SCHEME_CURRENT
```

Это отключает сон при питании от сети и разрешает работать при закрытой
крышке. Ноутбук должен быть подключён к зарядке.

## 6. Автозапуск после перезагрузки

`Win+R` → ввести `shell:startup` → положить туда ярлык на
`start-windows.bat`.

## Если проверка просит капчу каждый раз

Значит профиль не сохраняется: проверьте, что папка `collector\profile`
существует и в неё есть запись. Ещё вариант — Авито ужесточил проверку,
тогда решать её надо раз в несколько часов, а не один раз.
