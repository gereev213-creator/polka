# PNG-иллюстрации категорий

Сюда кладутся картинки плашек категорий. Vite копирует эту папку в сборку
как есть, поэтому с сервера они доступны по пути `/categories/<файл>`.

## Что нужно

Положите 10 файлов с **ровно такими именами** (регистр важен):

| Категория                          | Файл                    |
|------------------------------------|-------------------------|
| Другое                             | `other.png`             |
| Авто                               | `auto.png`              |
| Недвижимость                       | `realty.png`            |
| Аренда                             | `rent.png`              |
| Для дома и дачи                    | `home.png`              |
| Запчасти                           | `parts.png`             |
| Услуги                             | `services.png`          |
| Электроника                        | `electronics.png`       |
| Работа и подработка                | `jobs.png`              |
| Одежда, обувь, аксессуары          | `fashion.png`           |

## Требования к файлам

- **Формат:** PNG с прозрачным фоном (иллюстрация «вылезает» за край плашки,
  поэтому фон должен быть прозрачным, а не серым).
- **Размер:** примерно `500×420 px` (запас под retina). На плашке картинка
  показывается в области `124×102 px` и обрезается по краю плашки.
- **Композиция:** объект лучше ставить в правый нижний угол кадра — именно
  к этому углу он прижимается в вёрстке. Ничего важного не должно быть
  у самого низа и у правого края: эти части обрежутся.
- **Вес:** до ~150 КБ на файл, иначе лента и форма будут грузиться заметно
  дольше.

## Как это работает в коде

Соответствие «категория → файл» задано в `CATEGORY_IMAGES`
(`src/App.jsx`). Если файла нет или он не загрузился, показывается
встроенная SVG-иллюстрация — блок не ломается, поэтому картинки можно
добавлять по одной, в любом порядке.
