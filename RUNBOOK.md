# Сборщик: как запускать и что смотреть

## Запуск
```bash
nohup /tmp/polka-loop.sh > /tmp/polka-loop.err 2>&1 &
```
Внутри: выдача раз в 30 минут + поток характеристик по 3 карточки.

## Остановка
```bash
pkill -f polka-loop; pkill -f "collect.py"
```

## Где смотреть
| Что | Файл |
|---|---|
| Выдача (проходы) | `/tmp/polka-collector.log` |
| Характеристики | `/tmp/polka-details.log` |
| Ошибки запуска | `/tmp/polka-loop.err` |

Ищите строки: `→ avito:` (цель), `найдено карточек`, `принято`, `439` (блок).

## Если Авито блокирует
1. Остановить сборщик, подождать 2–3 часа.
2. Или поднять профиль браузера: `python3 /tmp/avito_auth.py` (нужно пройти проверку в окне).

## Что внутри
- прямые запросы, без прокси и скраперов;
- раздел определяется по слову товара (джинсы → одежда);
- отсев: тип товара, бренд (с апострофами), цена, аксессуары;
- LLM проверяет смысл (три бесплатные модели с перебором);
- характеристики (состояние, размер) — со страницы объявления, когда Авито отдаёт.
