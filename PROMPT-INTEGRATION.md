## Что уже работает

- Авторизация: заголовок `X-Telegram-Init-Data`, id пользователя берётся из initData
- Находки, мои поиски, создание критерия, избранное, история
- Модерация в приложении: `GET /api/moderation`, `POST /api/moderation/{id} {action: approve|reject}`
- Загрузка фото лота: `POST /api/ads/photos` (multipart, поле `photos`) → `{urls: []}`
- Публикация лота: `POST /api/ads` → создаётся со статусом `moderation`
- Тарифы: `GET /api/pay/plans`, оплата: `POST /api/pay/cispay/create` и `POST /api/pay/paw/create`
- Промокод: `POST /api/promo/redeem {code}`

## Что не доделано — это и есть задача

### 1. Оплата не срабатывает

Симптом: в приложении нажимаю «Оплатить» — «оплата не сделана», ничего не открывается.

Причины:
- CISPay на сервере выключен (`/health` показывает `cispay: false`), отвечает 503
- PayAnyWay включён (`paw_enabled: true`), но приложение не всегда до него доходит
- Нужно: при отказе одного провайдера пробовать второй, показывать понятную ошибку, вести пользователя на реальную платёжную форму
- Проверить весь путь: создание счёта → переход → `GET /api/pay/paw/status` → начисление подписки → `plan` в `/api/me` меняется на `plus`

### 2. Админ и аватар в профиле

Симптом: у админа нет пунктов «Админка» и «Модерация», нет аватарки и юзернейма.

Причины:
- В таблице `users` **нет колонки `photo_url`** — аватар надо брать из Telegram initData (`user.photo_url`)
- `is_admin` считается по `ADMIN_USER_IDS` (сейчас `6115882628`), но нужно сверить с реальным Telegram id пользователя
- Проверить: `/api/me` должен возвращать `user.is_admin`, `user.photo_url`, `user.username`

### 3. Проверить остальные экраны на «мёртвые» кнопки

Пройти каждый экран приложения и убедиться, что каждое нажатие делает что-то настоящее:
вход, находки, барахолка, карточка товара, новый поиск, мои поиски, история,
избранное, профиль, тарифы, мои объявления, создание лота, рефералка, модерация, правовые страницы.

## Правила работы

1. **Дизайн не менять.** Правки только в логике: `adapter.js`, `polka_bot-9-3.py`.
2. Если нужен новый эндпоинт — добавлять в `polka_bot-9-3.py` рядом с существующими, с проверкой `_miniapp_viewer` и `ADMIN_USER_IDS` для админских.
3. Любая правка сервера: `python3 -m py_compile polka_bot-9-3.py`, затем весь набор `tests/*.py` — должно быть 43/43.
4. Сборка фронта: `cd polka-final/frontend/proto && python3 build.py`, затем `cp index.html ../dist/index.html && cp adapter.js ../dist/adapter.js`.
5. Деплой: `git add -A && git commit && git push amvera master`. Amvera пересобирается 3–5 минут.
6. После деплоя проверять живьём: `https://polka-mini-app-nikicev2009.mia0.amvera.tech/health` → 200.

## Критерии готовности

- Кнопка «Оплатить» открывает платёжную форму либо говорит точную причину отказа
