# Воркер быстрого мониторинга (Windows)

Эта папка ставится на компьютер, который работает 24/7 (старый ноут). Воркер
открывает **видимый Chromium** с профилем, в котором Авито уже пускает, и раз
в несколько секунд читает выдачу. Новые объявления уходят на сервер Полки —
дальше они сами появляются в Telegram и в ленте «Находки».

Без этого воркера сервер мониторит ссылки через мобильный прокси: медленно
(1–2 минуты) и с блокировками. С воркером — секунды.

## 1. Остановить старый сборщик

Старый парсер и воркер не могут работать одновременно: они делят один профиль
браузера и один домашний IP.

- Диспетчер задач → завершить `python.exe` / `pythonw.exe`, если это старый
  `collect.py`.
- Или `schtasks /Delete /TN "PolkaCollector" /F`, если задача в Планировщике.
- Убрать `collect.py` из автозагрузки (Планировщик или папка «Автозагрузка»).

Найдите папку старого профиля Chromium — она нужна воркеру. Обычно это
`...\collector\profile` или путь из `browser.env` / `AVITO_PROFILE`.
Если не нашли — не страшно: воркер создаст новый профиль, и вы один раз
войдёте в Авито вручную (см. шаг 4).

## 2. Установить Python и зависимости

Нужен Python 3.10+ (на ноуте он уже есть — старый сборщик работал).

```bat
install-windows.bat
```

Скрипт поставит `playwright` и Chromium. Это один раз, ~2 минуты.

## 3. Прописать настройки

Откройте `start-worker.bat` в Блокноте и заполните:

```bat
set POLKA_SERVER=https://polka-mini-app-nikicev2009.mia0.amvera.tech
set LIVE_WORKER_TOKEN=токен_из_Amvera
set AVITO_PROFILE=C:\путь\к\старому\профилю
```

- `LIVE_WORKER_TOKEN` — переменная окружения в Amvera. Такой же токен нужно
  вписать здесь. Без него сервер не примет находки.
- `AVITO_PROFILE` — папка профиля Chromium. Если оставить `worker\profile`,
  воркер создаст новый профиль.

## 4. Первый запуск

```bat
start-worker.bat
```

Откроется окно Chromium. Если Авито просит проверку — **пройдите её вручную
один раз** (галочка/картинка). Профиль запомнит проверку. Дальше окно можно
свернуть, но не закрывать: воркер живёт, пока открыт браузер.

Проверка без цикла:

```bat
python worker.py --once
```

В логе (`worker.log`) будет `baseline N карточек` — значит, выдача читается.

## 5. Автозапуск

1. `Win+R` → `shell:startup` → Enter.
2. Положите туда ярлык на `start-worker.bat`.
3. В электропитании: «Переходить в спящий режим» → **Никогда**.

Воркер переживёт перезагрузку и продолжит с того же места (состояние в
`worker_state.json`).

## Что происходит на сервере

- Пока воркер присылает heartbeat (раз в 30 с), сервер **не** опрашивает
  ссылочные поиски через прокси — их ведёт воркер.
- Воркер замолчал на 2 минуты — сервер подхватывает ссылки на мобильном
  прокси (медленно, но находки не теряются).
- Находки воркера идут в тот же `ingest_findings`: чат, лента, история.

## Если что-то не так

- `401/403` в логе — неверный `LIVE_WORKER_TOKEN` (сверьте с Amvera).
- `HTTP 439/403` — профиль потерял доверие. Откройте браузер воркера,
  пройдите проверку вручную, перезапустите.
- `Профиль занят` — старый сборщик ещё работает, закройте его.
- Пусто в `worker.log` — смотрите `python worker.py --once` в консоли.
