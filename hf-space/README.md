# Свой ИИ для Полки

Маленькая модель, которая работает **бесплатно и без лимитов**: оценивает
объявления с Авито — оригинал или реплика, какая батарея, есть ли сколы.

**Адрес API после сборки:** `https://<ваш-логин>-polka-ai.hf.space/v1/chat/completions`

Он **совместим с OpenAI**, поэтому бот работает с ним без правок кода —
достаточно поменять три переменные в Amvera.

## Что внутри

- `Dockerfile` — образ с моделью (качается при сборке)
- `app.py` — сервер: принял запрос, вернул ответ в формате OpenAI

## Если модель не скачалась при сборке

Откройте страницу модели, вкладку **Files**, скопируйте точное имя файла
и подставьте в `MODEL_URL` в `Dockerfile`. Ссылка строится так:

```
https://huggingface.co/<репозиторий>/resolve/main/<имя-файла>
```
